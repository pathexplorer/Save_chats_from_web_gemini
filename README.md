# Save_chats_from_web_gemini
simple script for saving chats with Gemini, works as of May 2026

How run:
1. Open conversation
2. Scroll to the start of the conversation
3. Open DevTools window (F12)
4. Open console tab
5. Write "allow pasting" line (not needs press enter after)
6. Paste code to console
7. Press the floating blue button "Export gemini Chat"
8. Ready, you have .md file in your Download page

Current pitfalls:
- does not support saving image attachments in the questions
