# Save_chats_from_web_gemini
simple script for saving chats with Gemini, works as of May 2026

How run:
1. Open conversation
2. Open DevTools window (F12)
3. Open console tab
4. Write "allow pasting" line (not needs press enter after)
5. Paste code to console
6. Press the floating blue button "Export gemini Chat"
7. Ready, you have .md file in your Download page
